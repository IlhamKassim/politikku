Election Model Glossary

This is a quick reference guide to the core terms used in the PolitikKu election model.

Baseline

The historical fact. Specifically, the GE15 federal results for all 222 Seats. This acts as the starting point for any projection.

Swing Model

The method for turning Sentiment into a per-Seat or per-Coalition Swing. It applies a uniform swing within each state, blended with any State Election Signal for the state that voted. It is NOT fitted to demographic data per seat.

Sentiment

The measured public political mood, derived from open-source News Sentiment and Poll Calibration. It's the input signal that drives the Swing Model.

Seat Call

The projected outcome for a single Seat (e.g. which Coalition wins, and the margin). Crucially: A Seat Call is pure arithmetic (Baseline + Uniform State Swing), never a bespoke judgement about that specific constituency.

Projection

The tool's output based on the model. We use "Projection", never "Prediction" or "Forecast", to reflect that the model uses provisional constants and is not statistically calibrated for high precision.

MRP (Multilevel Regression and Poststratification)

The gold standard for modern predictive election forecasting. It combines large-scale polling with granular census data to predict shifts based on specific demographic groups per constituency. We specifically avoid this in favor of the Swing Model due to its high cost and lack of pure arithmetic transparency.
